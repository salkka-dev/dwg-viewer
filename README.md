# 도면 뷰어

아이패드에서 DWG, DXF 도면을 광고 없이 보고, 배치나 도곽 단위로 나눠 PDF로 바꾸는 개인용 웹앱입니다.
파일은 기기 안에서만 처리되고 어떤 서버로도 올라가지 않습니다. 홈 화면에 추가하면 앱처럼 열리고, 한 번 연 뒤에는 인터넷 없이도 씁니다.

## 할 수 있는 일

- DWG(R14부터 2018 형식까지)와 DXF 파일을 엽니다. 손가락 두 개로 확대하고 한 손가락으로 이동합니다.
- 한글 글꼴(whgtxt 계열 SHX, 굴림과 맑은 고딕 대체 글꼴)이 앱 안에 들어 있어 한글이 깨지지 않습니다.
- 레이어를 켜고 끄고, 모형과 배치 탭을 오가고, 배경을 검정과 흰색으로 바꿉니다.
- 최근 연 파일을 기기에 기억해 두고 다시 고르지 않아도 엽니다.
- PDF 변환은 배치(시트)마다, 또는 모형 공간에 나란히 놓인 도곽마다 한 장씩 만듭니다. 낱장 파일과 한 파일로 합친 PDF를 함께 줍니다. 용지(원본, A4~A1), 흑백과 컬러, 선 굵기 반영을 고릅니다. 선과 글자가 벡터로 들어가서 확대해도 깨지지 않습니다.
- 편집 버튼을 누르면 선, 폴리선, 사각형, 원, 호, 글자, 치수, 수정 구름을 그리고 이동, 복사, 회전, 간격 띄우기, 지우기, 되돌리기를 합니다. 아이패드에서는 화면을 길게 누르면 돋보기와 십자선이 떠서 점을 정확하게 찍습니다. PC에서는 마우스로 찍고 Enter와 Esc를 씁니다.
- 고친 도면은 원본을 건드리지 않고 `이름_수정.dxf`(DXF 2018, 한글 UTF-8)로 저장합니다. AutoCAD에서 열어 DWG로 다시 저장하면 됩니다.
- 구글 드라이브 연결은 `src/config.ts`에 구글 클라우드 OAuth 클라이언트 ID를 넣으면 켜집니다. 드라이브 폴더를 앱 안에서 열고, 고친 도면을 원래 폴더에 바로 저장합니다.

## 아이패드에 설치하기

1. 아이패드 Safari에서 [https://salkka-dev.github.io/dwg-viewer/](https://salkka-dev.github.io/dwg-viewer/)를 엽니다. 크롬 같은 다른 브라우저는 홈 화면 앱으로 설치되지 않습니다.
2. 주소창 옆 공유 버튼(네모에 위쪽 화살표)을 누르고 "홈 화면에 추가"를 고릅니다.
3. 이름을 확인하고 "추가"를 누르면 홈 화면에 도면 뷰어 아이콘이 생깁니다.
4. 아이콘으로 한 번 실행해 두면 "이제 인터넷 없이도 열려요" 안내가 뜹니다. 그 뒤로는 비행기 모드에서도 열립니다.

## 쓰는 법

- 파일 열기를 누르면 아이패드 파일 앱이 열립니다. iCloud Drive, 내 iPad, 파일 앱에 연결해 둔 구글 드라이브 어디서든 고를 수 있습니다.
- PDF 버튼을 누르면 찾아낸 페이지 목록이 나옵니다. 보기를 누르면 그 영역으로 화면이 이동해서 맞게 잡혔는지 확인할 수 있습니다.
- PDF 만들기가 끝나면 모두 저장을 누릅니다. 공유 시트에서 "파일에 저장"을 고르면 낱장 PDF가 한꺼번에 저장됩니다.

## 개발

```bash
npm install
npm run dev
```

`npm run build` 결과물(`dist`)은 정적 파일이라 GitHub Pages 같은 HTTPS 호스팅에 그대로 올리면 됩니다. 저장소의 `.github/workflows/deploy.yml`이 main 브랜치에 올라올 때마다 GitHub Pages로 배포합니다.

## 만든 재료

- 도면 해석과 화면 표시는 [MLightCAD cad-viewer](https://github.com/mlightcad/cad-viewer) 엔진(MIT)을 씁니다.
- DWG 읽기는 [LibreDWG](https://www.gnu.org/software/libredwg/)를 웹어셈블리로 옮긴 `@mlightcad/libredwg-web`(GPL-3.0)을 씁니다. 그래서 이 앱도 GPL-3.0을 따릅니다.
- 글꼴 파일은 [mlightcad/cad-data](https://github.com/mlightcad/cad-data)에서 한글과 기본 SHX 위주로 골라 담았습니다.
